# 搭配其他第三方套件配置

若想用第三方，也想型別檢查。

重點主要以下:
- 若本身套件有提供，如: axios
- TS官方有提供該第三方套件的型別檢查，需查詢: https://www.npmjs.com/~types
- 若本身套件、TS官方都沒有提供，建議換掉該第三方套件

```js
mport axios from "axios"; 
import type { AxiosResponse } from "axios"; // axios ⾃⼰有提供宣告檔案

import _ from "lodash"; //找不到模組 'lodash' 的宣告檔案。 npm i --save-dev @types/lodash

import type { SwiperOptions } from "swiper/types"; // 官⽅提供的宣告檔案
```
