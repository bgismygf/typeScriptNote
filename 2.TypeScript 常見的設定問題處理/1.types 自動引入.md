# types 自動引入

到 tsconfig.json 加入:

```json
"include": ["src/**/*"]
```

原先需要 export type，設定完後就可以直接使用。

```js
// 原先
// export type TUserBaseType = {
//     name: string;
//     age: number;
//     userAddress: string;
// };

// export type TUserJobType = {
//     companyName: string;
//     jobTitle: string;
//     seniority: number;
//     companyAddress: string;
// };

// 變成全域，可直接使用
type TUserBaseType = {
    name: string;
    age: number;
    userAddress: string;
};

type TUserJobType = {
    companyName: string;
    jobTitle: string;
    seniority: number;
    companyAddress: string;
};
```
