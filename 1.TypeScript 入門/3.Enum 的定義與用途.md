# Enum 的定義與用途

> 1. 提⾼代碼的可讀性與可維護性：Enum 允許開發者使⽤有意義的名稱來代替
數字或字符串，使得代碼更加直觀且易於理解。 
>
> 2. 確保類型安全：Enum 限制了變量的值必須是列舉中定義的⼀個成員，這樣
可以避免使⽤不正確的值。 
>
> 3. ⽀持反向映射：數字 Enum ⽀持反向映射，即可以從數字值獲取對應的名
稱，這在某些情況下非常有⽤。

### 列舉寫法

```js
// 星期幾
enum DaysWeek {
  Monday,
  Tuesday,
  Wednesday,
  Thursday,
  Friday,
  Saturday,
  Sunday,
}

function getTodaySpecial(day: DaysWeek) {
  switch (day) {
    case DaysWeek.Monday:
      return "星期一大特價: 買一送一!";
    case DaysWeek.Tuesday:
      return "星期二大特價: 三人同行一人免費!";
    case DaysWeek.Wednesday:
      return "星期三大特價: 五折優惠!";
    case DaysWeek.Thursday:
      return "星期四大特價: 三人同行一人免費!";
    case DaysWeek.Friday:
      return "星期五大特價: 五折優惠!";
    case DaysWeek.Saturday:
      return "星期六大特價: 買一送一!";
    case DaysWeek.Sunday:
      return "星期日大特價: 三人同行一人免費!";
    default:
      return "今天沒有特價活動!";
  }
}

console.log(getTodaySpecial(DaysWeek.Monday)); // 星期一大特價: 買一送一!
```

### 反向映射

```js
// 非同步錯誤代碼
enum StatusErrorCodes {
  NotFound = 404,
  Forbidden = 403,
  Unauthorized = 401,
}


// 也能寫成 code = 0
// 因為 ts 自動型別推導出值(404, 405..) 是數字
// 如果沒有值，無法型別推導，就需要放列舉，如 code: StatusErrorCodes
// function handleError(code = 0) {...}

function handleError(code: StatusErrorCodes) {
  switch (code) {
    case StatusErrorCodes.NotFound:
      console.log("ERROR: 沒有這個東西");
      break;
    case StatusErrorCodes.Forbidden:
      console.log("ERROR: 禁止存取");
      break;
    case StatusErrorCodes.Unauthorized:
      console.log("ERROR: 未經授權");
      break;
    default:
      console.log("ERROR: 未知的錯誤");
  }
}
// 用 key 取值
console.log(handleError(StatusErrorCodes.Forbidden)); // 403
// 用值取 key
console.log(handleError(StatusErrorCodes[403])); // Forbidden
```
