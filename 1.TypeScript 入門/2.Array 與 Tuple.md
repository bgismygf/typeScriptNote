# Array 與 Tuple

### tuple(元祖)寫法

```js
const tuple1: [number, string] = [1, "a"];
```

### 設定類型的順序要與值的順序一致，數量也一致

```js
const tuple2: [string, number] = ["a", 1]; // error -> 不可以改變類型順序
const tuple3: [number, string, number] = [1, "a", 2]; // error -> 不可以多加類型

// 可選
const tuple4: [number, string, number?] = [1, "a"];
const tuple5: [number, string, number?] = [1, "a", 2];

// 剩餘元素
const tuple6: [number, ...number[]] = ["a", 2, 3, 4 ,5];

// 不可修改，readonly 只有 tuple 能用
const tuple7: readonly [number, string] = [1, 'a'];
```

### 差異

Array泛型可以彈性的去設定值的類型，tuple 則需要一個蘿蔔一個坑的去設定，取決於設定的要多嚴謹。
