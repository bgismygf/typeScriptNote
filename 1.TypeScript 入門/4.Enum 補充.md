# Enum 補充

沒填入值，列舉會預設 index，滑鼠指過去會顯示 `DaysWeek.Monday = 0`。

```js
enum DaysWeek {
  Monday = 13,
  Tuesday, // 14
  Wednesday, // 15
  Thursday, // 16
  Friday,
  Saturday,
  Sunday,
}
// key 取值
console.log(DaysWeek.Monday); // 0
// 值取 key
console.log(DaysWeek[0]); // "Monday"
```

如果給第一個值為 13，接下來的值會接續 14、15...

```js
enum DaysWeek {
  Monday = 13,
  Tuesday, // 14
  Wednesday, // 15
  Thursday, // 16
  Friday,
  Saturday,
  Sunday,
}
```

如果第一個值為字串，接下來的值無法型別推導給預設，會出現紅色波浪。

需要每個列舉加上值。

```js
// 須加上值
enum DaysWeek {
  Monday = 'Monday',
  Tuesday,
  Wednesday,
  Thursday,
  Friday,
  Saturday,
  Sunday,
}
```
