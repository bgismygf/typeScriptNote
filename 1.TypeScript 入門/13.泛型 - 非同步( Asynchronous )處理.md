# 泛型 - 非同步( Asynchronous )處理

## 重點

- Promise<...>
- axios 的 AxiosResponse

### fetch 範例

```js
async function apiRequest(url) {
  const response = await fetch(url);
  const data = await response.json();
  return {status: response.status, data}
}

apiRequest("https://vue-lessons-api.vercel.app/photo/list").then((res) => {
  console.log("API then=>", res.data);
});
```

改寫後:

```js

type ApiResponse<T> = {
  status: number;
  data: T;
};

type TPhotoList = {
  url: string;
};


async function apiRequest<T>(url: string): Promise<ApiResponse<T>> {
  const response = await fetch(url);
  const data = await response.json() as T;
  return {status: response.status, data}
}

apiRequest<TPhotoList[]>("https://vue-lessons-api.vercel.app/photo/list").then((res) => {
  console.log("API then=>", res.data);
});
```

#### fetch 範例 - 用法

回傳結果是 Promise，所以用 `Promise<...>`。

`Promise<...>` 箭頭內，是回傳結果的資料格式，要先知道回傳結果是什麼。

```js
// 回傳結果
{
    status: 200,
    data: [
        {
            url: 'https://vue-l...';
        },
        {
            url: 'https://vue-l...';
        },
    ]
}
```

`T` 用來定義 data 的資料格式。

```js
async function apiRequest<T>(url: string): Promise<{status: number, data: T}> {
  const response = await fetch(url);
  const data = await response.json() as T;
  return {status: response.status, data}
}
```

定義 data 內的物件資料格式 :

```js
// {
//     url: 'https://vue-l...';
// },

type TPhotoList = {
  url: string;
};
```

定義函式的資料格式 :

```js
type ApiResponse<T> = {
  status: number;
  data: T;
};
```

帶入格式。

```js
async function apiRequest<T>(url: string): Promise<ApiResponse<T>> {
  const response = await fetch(url);
  const data = await response.json() as T;
  return {status: response.status, data}
}

// 呼叫時帶入 -> 陣列格式的 TPhotoList 物件
apiRequest<TPhotoList[]>("https://vue-lessons-api.vercel.app/photo/list").then((res) => {
  console.log("API then=>", res.data);
});

const res = await apiRequest<TPhotoList[]>("https://vue-lessons-api.vercel.app/photo/list")
console.log("API await=>", res.data);
```

### axios 範例

```js
import axios, { AxiosResponse } from "axios";

axios.get<TPhotoList[]>("https://vue-lessons-api.vercel.app/photo/list").then((res: AxiosResponse<TPhotoList[]>) => {
  console.log("axios=>", res.data);
});

function apiGetPhotoList(): Promise<AxiosResponse<TPhotoList[]>> {
  return axios.get("https://vue-lessons-api.vercel.app/photo/list");
}

const resPhoto = await apiGetPhotoList();
console.log("photo list=>", resPhoto.data);
```

#### fetch 範例 - 用法

`AxiosResponse` 是 axios 提供回傳結果的型別。第三方套件若有提供，可直接使用。

如果像 apiGetPhotoList 一樣包裹 axios，寫法為:回傳的是 Promise

```JS
// axios 回傳的是 Promise > AxiosResponse 型別格式 > TPhotoList[] 資料型別格式
function apiGetPhotoList(): Promise<AxiosResponse<TPhotoList[]>> {...}
```
