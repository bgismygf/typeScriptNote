# 函式定義 ( function type 定義 )

## 寫法

```js
let introduce: string = '';

// 不回傳值，小括號後方加上 void
function a1Fun(name: string, age: number): void {
  introduce = `我叫${name}，今年${age}歲`;
};

// 要傳值，小括號後方型別
function a2Fun(name: string, age: number): string {
  return `我叫${name}，今年${age}歲`;
};
```

## 箭頭函式寫法

```js
const add: number = (a: number, b: number): number => a + b;

// 過長，可用 type 改寫
type IHandleNumber = {
  (a: number, b: number): number;
};

const add2: IHandleNumber = (a, b) => a + b;
```
