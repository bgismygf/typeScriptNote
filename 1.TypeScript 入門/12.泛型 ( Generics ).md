# 泛型 ( Generics )

```js
function resArg(arg) {
    return arg;
}
```

1. 在不知道傳入什麼參數時，很難定義參數型別。
2. 如果寫死或使用 `|` 也會太長。

```js
// 太長、不確定且寫死
// 除非很明確要放 string 和 number
function resArg(arg: string | number) {...}
```

## 寫法1

1. T 是自定義關鍵詞，可以定義其他詞，如 U、R...。
2. T 在函式呼叫時傳入的型別
3. 傳入後，函式的參數和傳出來的型別，都可以使用 T 這個設定。


```js
function resArg<T>(arg: T): T {
    return arg;
}

// 定義 number，參數傳入是 number，傳出是 number
const res1 = resArg<string>("Mike");

const res2 = resArg<number>(100);
```

## 寫法2

參數傳入 array，回傳 array 內的 item。

```js
function getFirstItem<T>(arr: T[]): T {
  return arr[0];
}

const numbers = [1, 2, 3, 4];
const firstNumber = getFirstItem(numbers);
console.log(firstNumber); // => 1

const strings = ["a", "b", "c", "d"];
const firstString = getFirstItem(strings);
console.log(firstString); // => "a"
```
