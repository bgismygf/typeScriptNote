# 全部可選的 Partial

## 重點
- 問號(?)
- Partial

### 用問號(?)

用 ? 讓 address 是可選

```js
type TUserDataInfo = {
  name: string;
  age: number;
  address?: string;
};
```

### Partial

把所有的屬性變成可選的。

可視為全部屬性名稱都帶上問號(?)

```js
type TUserDataInfo = {
  name: string;
  age: number;
  address: string;
};

// 把所有的屬性變成可選的
const user1: Partial<TUserDataInfo> = {
  name: "Mike",
  age: 12,
};

// 直接使用是沒辦法的
const user2: TUserDataInfo = { // <- 紅波浪
  name: "Mike",
  age: 12,
};
```
