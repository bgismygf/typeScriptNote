# DOM 的 type

```html
<body>
    <div id="app">
      <h1 class="title">請填入名字</h1>
      <input class="inpTxt" type="text" placeholder="請填入名字" />
      <button class="send">送出</button>
    </div>
</body>
```

1. 當指到 html 的元素內，會出現 MDN Reference 提示。

2. 按下 MDN Reference 後出現 MDN 網頁。

3. 網頁尋找 DOM 接口 或 DOM interface 的表格列標題，對應的是 `HTMLInputElement`、`HTMLButtonElement`...等類型。

即可用來寫 DOM 的類型。

再未抓到 DOM 元素前，該變數會是 null，所以要加上 `| null`。

```js
const titleRef: HTMLHeadingElement | null = document.querySelector(".title");
const inpTxtRef: HTMLInputElement | null = document.querySelector("input.inpTxt");
const sendRef: HTMLButtonElement | null = document.querySelector(".send");
```
