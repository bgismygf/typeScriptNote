# 管理 type or Interfaces

當 type 太多，可以另開檔案去存取。

可以開一個資料夾 type 去存放。

範例: `./type/TUserType.ts`

```js
export type TUserBaseType = {
    name: string;
    age: number;
    userAddress: string;
};

export type TUserJobType = {
    companyName: string;
    jobTitle: string;
    seniority: number;
    companyAddress: string;
};
```

引用時:

```js
import { TUserBaseType, TUserJobType } from "./type/TUserType.ts";


const userData: TUserBaseType & TUserJobType = {
    name: "Mike",
    age: 12,
    companyName: "TheCodingPro",
    jobTitle: "Teacher",
    seniority: 3,
    userAddress: "台灣桃園市",
    companyAddress: "台灣台北市",
};
```
