# any 與 unknown

## any

使用 any，等於，不會進行型別檢查

```js
let count: any = 3;
count = "3";

// 不會進行型別檢查
// count 是字串
// 字串沒有 toFixed 的方法，等到編譯後，運行時就會報錯
console.log(count.toFixed()); // 錯誤
```

## unknown

類似 any，當要使用該變數時，需要寫型別檢查

```js
const price: unknown = 3.14159;

// 當我今天想要使用 number 才有的方法時，就需要進行型別檢查
if (typeof price === "number") {
  console.log(price.toFixed()); // -> '3'
}
```
