# props defaults

## 原先寫法

如果這樣寫，就不能寫預設值。

```vue
<script setup lang="ts">
const props = defineProps<{
  name: string;
  age?: number; // 可傳可不傳
  info: {
    email: string;
    phone: string;
  };
}>();
</script>
```

## 改寫

- 使用 `withDefaults()`
- 參數兩個 defineProps<TUser>()、預設值

```vue
<script setup lang="ts">
type TInfo = {
  email: string;
  phone: string;
};

type TUser = {
  name: string;
  age: number;
  info: TInfo;
};
// 當使用 type定義型別時，我們失去了為 props 設定預設值的功能。可以透過 withDefaults 解決
const props = withDefaults(defineProps<TUser>(), {
  name: "Mike",
  age: 27,
  info: () => ({ email: "", phone: "" }),
});
</script>

<template>
  <div>
    <pre>
      {{ props }}
    </pre>
  </div>
</template>
<style></style>
```

## 補充

```ts
type TProps = {
  coursesArr: TCourses[];
  coursesId: number;
  getDetal: (id: number) => void; // 傳入 function，function 參數是 id:number，不需回傳
  openUrl: (url: string) => void;
  closePopup: () => void; // 沒參數，不需回傳
};

const props = withDefaults(defineProps<TProps>(), {
  coursesArr: () => [],
  coursesId: 0,
  getDetal: (id: number) => {},
  openUrl: () => {},
  closePopup: () => {},
});
```
