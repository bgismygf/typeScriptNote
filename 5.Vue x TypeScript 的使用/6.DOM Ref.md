# DOM Ref

當 `const el = ref<HTMLInputElement>(null);` 時，會出現 `null 不可指派 HTMLInputElement 的參數`，須改為 `HTMLInputElement | null`。

```vue
<script setup lang="ts">
import { ref, onMounted } from "vue";

const el = ref<HTMLInputElement | null>(null);

onMounted(() => {
  el.value?.focus();
});
</script>

<template>
  <div>
    <input type="text" />
  </div>
</template>
```
