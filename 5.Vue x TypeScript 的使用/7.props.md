# props

### 原先 vue 寫法

```vue
<script setup lang="ts">
const props = defineProps({
    name: {
      type: String,
      default: "ming"
    },
    age: {
      type: Number,
      default: "ming"
    },
    info: {
      type: Object,
      default: () => ({
        email: "12086556@gmail.com",
        phine: "0923-658-965",
      })
    },
});
</script>
```

### 改寫

```vue
<script setup lang="ts">
const props = defineProps<{
  name: string;
  age?: number; // 可傳可不傳
  info: {
    email: string;
    phone: string;
  };
}>();
</script>
<template>
  <div>
    <pre>
      {{ props }}
    </pre>
  </div>
</template>
```
